# راهنمای Local Business Reviews 1.3.5

افزونه وردپرس برای نمایش ریویوها، امتیاز، تعداد نظرات و اطلاعات گوگل بیزینس پروفایل؛ نوشتهٔ **علی پورقلی**.

[English guide](README.md)

این افزونه مستقل است و محصول رسمی گوگل نیست. برای اتصال باید مالک یا مدیر پروفایل باشید و پروژهٔ Google Cloud با دسترسی تأییدشده به Business Profile API داشته باشید. افزونه با وارد کردن Place ID هر کسب‌وکار دلخواه کار نمی‌کند. هیچ کلید، توکن یا دادهٔ مشتری همراه کد منتشر نشده است.

## پیش‌نیازها

- وردپرس ۶.۲ یا بالاتر، PHP 7.4 یا بالاتر و OpenSSL با AES-256-GCM.
- سایت HTTPS و دسترسی خروجی هاست به سرویس‌های گوگل.
- حساب مدیر/مالک کسب‌وکار، پروژهٔ تأییدشده و OAuth Client از نوع Web application.

## نصب

۱. در GitHub گزینهٔ Code و سپس Download ZIP را بزنید و فایل را استخراج کنید.
۲. نام پوشهٔ استخراج‌شده را `local-business-reviews` بگذارید؛ فایل `local-business-reviews.php` باید مستقیم داخل آن باشد.
۳. پوشه را در `wp-content/plugins/` بارگذاری کنید؛ یا همان پوشه را ZIP کرده و از «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب کنید.
۴. افزونهٔ Local Business Reviews by Ali Pourgholi را فعال کنید.
۵. به Settings → Google Business Reviews بروید.

نیازی به npm یا Composer نیست. ابتدا روی سایت آزمایشی نصب کنید.

## اتصال به گوگل

۱. [پیش‌نیازهای Google Business Profile API](https://developers.google.com/my-business/content/prereqs) را بررسی و برای پروژه دسترسی دریافت کنید.
۲. APIهای My Business Account Management، My Business Business Information و Google My Business برای ریویوها را فعال کنید.
۳. صفحهٔ رضایت OAuth را تنظیم کنید و scope زیر را اضافه کنید:

```text
https://www.googleapis.com/auth/business.manage
```

۴. یک OAuth Client از نوع **Web application** بسازید. نشانی Redirect URI را دقیقاً از تنظیمات افزونه کپی و در Google Cloud ثبت کنید.
۵. Client ID و Client secret را در تنظیمات افزونه ذخیره کنید. روی Connect Google بزنید و با حساب مدیر یا مالک کسب‌وکار وارد شوید.
۶. Load my business profiles را بزنید، پروفایل درست را انتخاب کنید و Sync now را اجرا کنید.

تأیید دسترسی API با تأیید برنامهٔ OAuth متفاوت است. در حالت Testing، توکن نوسازی برای این scope معمولاً پس از ۷ روز منقضی می‌شود. قبل از استفادهٔ دائمی، وضعیت انتشار و الزامات تأیید گوگل را بررسی کنید. افزونه فقط اطلاعات را می‌خواند؛ پروفایل را ویرایش نمی‌کند و پاسخ ریویو ارسال نمی‌کند.

## نمایش در صفحه

در ویرایشگر وردپرس بلوک Shortcode اضافه کنید:

```text
[ap_google_business]
[ap_google_business style="carousel" autoplay="no" count="9" theme="auto"]
[ap_google_business style="grid" count="6" info="yes"]
[ap_google_rating theme="light"]
```

| گزینه | کاربرد |
| --- | --- |
| `style` | `grid`، `minimal`، `spotlight`، `carousel`، `wall` |
| `theme` | `auto`، `light`، `dark` |
| `count` | ۱ تا ۵۰ نظر؛ پیش‌فرض ۶ |
| `layout="carousel"` | اسلایدر برای هر سبک |
| `autoplay="yes"` | حرکت خودکار هر ۳ ثانیه در اسلایدر |
| `info="yes"` | تلفن و ساعات کاری در حالت غیر اسلایدری |
| `related="no"` | نمایش نظرات عمومی کسب‌وکار بدون اعمال قانون صفحه |

رنگ‌های قرمز، سبز و آبی، عنوان و لوگو از تنظیمات انتخاب می‌شوند. کنترل‌های افزونه فعلاً انگلیسی‌اند؛ جهت متن نظر به‌صورت خودکار تعیین می‌شود.

**محدودیت نسخهٔ ۱.۳.۵:** کد جاوااسکریپت از دکمهٔ توقف/ادامه پشتیبانی می‌کند، اما قالب PHP این دکمه را نمایش نمی‌دهد. اگر دکمهٔ توقف دائمی لازم است، `autoplay="no"` را نگه دارید. حرکت خودکار هنگام تعامل و با تنظیم کاهش حرکت سیستم متوقف می‌شود.

## نظرات مرتبط با هر صفحه

در Settings → Reviews by page صفحه را انتخاب کنید، تطبیق را فعال و عبارت‌های مرتبط با خدمت را وارد کنید. نتیجه را بررسی کنید؛ افزودن خودکار به انتهای محتوا اختیاری و در ابتدا خاموش است. می‌توانید نظرات مرتبط را دستی Include یا Exclude کنید؛ حذف دستی اولویت دارد.

تطبیق بر اساس عبارت‌های متن مشتری است؛ هوش مصنوعی نیست. پیشنهادهای آماده بیشتر برای خدمات برق و لوله‌کشی‌اند، اما عبارت دلخواه برای مشاغل دیگر قابل ثبت است. اگر نظر مرتبط نبود، می‌توان یک نظر عمومی مناسب و دارای برچسب نمایش داد. امتیاز و تعداد بالای بخش همیشه مربوط به کل کسب‌وکار است.

## کش و حریم خصوصی

همگام‌سازی هر ۱۵ دقیقه با WP-Cron تلاش می‌شود و به بازدید سایت وابسته است. کش افزونه تا ۲۴ ساعت معتبر است. حداکثر ۵۰۰ نظر اخیراً به‌روزشده دریافت می‌شود. هر نصب یک کسب‌وکار انتخاب‌شده دارد.

HTML اولیه شامل نسخهٔ کش‌شده است؛ جاوااسکریپت در بارگذاری و سپس هر ۵ دقیقه آن را بررسی می‌کند. کش کامل صفحه یا CDN ممکن است HTML قدیمی را نگه دارد؛ زمان اعتبار مناسب تنظیم کنید و پس از قطع اتصال کش صفحات را پاک کنید. درخواست `admin-ajax.php` با action برابر `aplr_public` باید مجاز و از کش CDN مستثنا باشد. بدون جاوااسکریپت، کنترل‌های اسلایدر و نوسازی/حذف محتوای منقضی اجرا نمی‌شوند.

کلید و توکن‌ها در دیتابیس با استفاده از salts وردپرس و نشانی سایت رمزگذاری می‌شوند؛ پس از مهاجرت یا تغییر salts اتصال را دوباره انجام دهید. تصاویر کاربران ممکن است از گوگل دریافت شوند. افزونه ریویوی ساختگی یا اسکیما تولید نمی‌کند و تضمینی دربارهٔ ایندکس شدن نظرات ندارد.

قبل از حذف افزونه، Disconnect کنید تا دسترسی گوگل لغو شود. غیرفعال‌سازی فقط زمان‌بندی را متوقف می‌کند؛ حذف افزونه تنظیمات، کش و قوانین صفحات را پاک می‌کند. رمزها، توکن‌ها و خروجی دیتابیس را در GitHub Issues قرار ندهید.

## عیب‌یابی

| مشکل | بررسی |
| --- | --- |
| `redirect_uri_mismatch` | نشانی HTTPS و query string دقیقاً مطابق افزونه باشد |
| خطای ۴۰۳ | تأیید پروژه، فعال بودن APIها و دسترسی حساب |
| خطای ۴۲۹ یا سهمیه صفر | وضعیت تأیید دسترسی و سهمیهٔ پروژه |
| فهرست پروفایل خالی | حساب درست و دعوت مدیریت پذیرفته‌شده |
| نظرات نمایش داده نمی‌شوند | انتخاب پروفایل، Sync موفق، اعتبار کش و اجازهٔ AJAX |
| قطع اتصال پس از مهاجرت | ورود دوبارهٔ اطلاعات OAuth و اتصال مجدد |

## وضعیت انتشار و مجوز

کدهای اجرایی همان نسخهٔ ۱.۳.۵ هستند؛ راهنما برای انتشار عمومی اصلاح شده است. بررسی سورس و نحو جاوااسکریپت انجام شد؛ اجرای PHP، تست نصب تازهٔ وردپرس و اتصال زندهٔ Google OAuth/API در این انتشار انجام نشده است. انتشار GitHub تغییری در سایت اصلی ایجاد نمی‌کند.
